# Inside a Machine Dream — 剧本

由 `config/build_timeline.py` 自动导出。渲染语言：只英文（中文列仅供参考）。字幕和章节名用机器字体 JetBrains Mono，像素点阵 + 解码出现。

全片用机器的眼睛看：画面重采样成格子，格子随节拍跳动、光和颜色在格子里流动，主体处格子更细。第 0 帧 = 最后一帧 = 几千块名画碎片组成的一只眼睛（无缝循环），瞳孔里的光点就是两指之间的缝隙。

转场都是机器在处理图像：网格坍缩 = 换章节，递归分裂 = 信息增加，像素排序 = 图像混合，潜空间渐变 = 梦 / 回忆，网格断裂 = 噩梦 / 过载；外加少量硬切。

第四章左上角是机器的分类读数（〔HUD〕行）。置信度数字是艺术化的虚构界面，不是任何真实模型的输出。

v13：每个镜头是一个视觉事件（见画面列）。深度、分割、骨骼、特征相似度来自本机模型的分析数据，只驱动几何和机器感知层；画面像素全部来自名画原图和程序生成，没有 AI 生成图像。“微型世界”全片 4 次（星 / 像素 / 砖 / 眼）。

关机：右上角 0:03 起显示红字 `SHUTDOWN mm:ss`（真实剩余时间 300 − t）和 `MEMORY nn%`（`timeline.json` 的 memory 轨道，结尾 1%），无底框，不规则地短暂断续，MEMORY 越低越频繁，最后 1 秒保持可见。读数下降时全片的画一块块变黑消失，每个镜头收尾再删一段：1:10 只有零星黑块，3:03 约删三分之一，4:21 约剩两成，4:42 约剩一成。《创造亚当》从不被删，名画之眼的幸存碎片到结尾全部换成它。低频嗡鸣随 MEMORY 变弱，最后 3 秒只剩音乐。

声音：音乐本身不动。4:00 “Every painting.” 处音乐压低 38 dB，只剩机器嗡鸣进入宇宙微波背景；五处视觉事件加很轻的自合成音效：塔冲出画面、影子爬向镜头、坠入黑暗、关系网络展开、光粒子聚成手。
